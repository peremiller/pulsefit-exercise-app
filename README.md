# PulseFit Professional Rebuild

A polished, mobile-first fitness web app with exercise-specific posture photography, embedded form videos, guided timers, and preserved local progress tracking.

## Included

- Eight home exercises with real posture imagery and coaching cues
- In-app YouTube demonstration players
- Search and muscle-group filters
- Guided duration controls and countdown sessions
- Favorites and completed-movement progress
- Training plans, 30-day challenges, hydration, cardio, body metrics, and workout history
- Clean URL routes for Today, Plan, Cardio, Body, Library, and Progress
- Graphify workflow and ignore rules

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Connect this directory to the Vercel project that owns `pulsefit-exercise-app.vercel.app`, then deploy the production build.
